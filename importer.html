Upload your parcel list
Accepts CSV or Excel (.xlsx). First row must be column headers. One row per parcel — not one row per owner.
Required: a Parcel # column. Everything else is optional — situs address, coordinates, acquisition type, status, notice date, notes.
Owners: map an Owner email or Owner name column and each parcel is attached to that contact — but only on an exact match against contacts already on this project. Nothing is guessed, and unmatched rows still create the parcel so you can attach the owner by hand.
Several owners on one parcel? Import the parcel once, then attach the co-owners in the Parcels view. A second row with the same parcel number is treated as a duplicate and skipped.
